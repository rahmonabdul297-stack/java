Java OOP Assignment

**Question 1 — Student Management System**

Create a Java class called `Student` with the following properties:

* `name`
* `matricNumber`
* `department`
* `level`
* `cgpa`

Create a constructor to initialize all the properties. Create a method `displayStudent()` to display the student's information.

In `main()`, create **3 Student objects** and display their information.

---

**Question 2 — Bank Account System**

Create a Java class called `BankAccount` with:

* `accountName`
* `accountNumber`
* `balance`

Use a constructor to initialize the properties.

Create methods to:

* `deposit()` money into the account
* `withdraw()` money from the account
* `displayAccount()` details

In `main()`, create **2 BankAccount objects**, perform deposits and withdrawals, then display their final account details.

**OOP concepts covered:** Classes, Objects, Constructors, Methods, and Encapsulation.
