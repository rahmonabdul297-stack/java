🔥 Advanced OOP Challenge — Java

Build a Banking System using OOP.

Create these classes:

BankAccount
SavingsAccount
CurrentAccount
Customer

Requirements

1. BankAccount

accountNumber

accountName

balance

Make all fields private.

Create a constructor.

Create deposit(), withdraw(), and getBalance() methods.


2. SavingsAccount extends BankAccount

Override withdraw().

A savings account must always maintain a minimum balance of ₦5,000.


3. CurrentAccount extends BankAccount

Override withdraw().

Allow the customer to withdraw up to ₦20,000 beyond the current balance as an overdraft.


4. Customer

name

customerId

Store multiple bank accounts belonging to the customer.

Add a method to display all the customer's accounts.


Main challenge

In main():

1. Create one Customer.


2. Create a SavingsAccount and a CurrentAccount.


3. Add both accounts to the customer.


4. Deposit money into both accounts.


5. Attempt different withdrawals.


6. Display the customer's accounts and final balances.



💀 Extra requirement

You must use polymorphism.

For example, your accounts should be stored like:

BankAccount[] accounts = new BankAccount[2];

Then use a loop to perform operations on them.

Don't create separate withdrawal logic in main() for Savings and Current accounts.
